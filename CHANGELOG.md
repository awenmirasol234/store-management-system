# Changelog

## Unreleased

## 1.0.0 - 2026-11-26

### Added

- StoreFlow POS with inventory, products, selling options, stock movements, and barcode support.
- POS checkout with cart management, discounts, custom amounts, returns, and receipt numbering.
- Customer credit, cashier shifts, cash drawer reconciliation, reports, CSV export, and receipt customization.
- Owner setup, staff management, PIN authentication, sessions, and role-based access.
- Responsive UI, collapsible navigation, charts, product images, feature configuration, Docker, and CI publishing.
- Reference-only and opt-in demo database seeding.

### Changed

- Improved product entry, checkout, reports, settings, tables, dialogs, spacing, and responsive layouts.
- Refreshed demo products, suppliers, categories, prices, inventory, and sales.
- Added version display and deployment documentation.

### Fixed

- Improved API validation, security, stock validation, shift ownership, database seeding, settings saving, and data integrity.
- Fixed responsive layout, table overlap, duplicate errors, cart persistence, and image-upload retry issues.

### Removed

- Removed unused dashboard trend charts and redundant UI actions.
